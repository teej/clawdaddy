# Research Plan — Delights / Serendipity (2026-02-03)

## Objective
Create a game/entertainment‑driven delight strategy for ClawDaddy (audio‑first coordinator + sub‑agents), emphasizing playful, viral, and serendipitous moments while staying within single‑sprite animation constraints and the spec’s “non‑chatty coordinator” model.

## Constraints
- Single‑sprite character (no multi‑sprite rigs).
- Coordinator is fast + minimal; no long chat threads.
- Sub‑agents surface status via bubbles; no audio responses.
- macOS native SwiftUI, always‑on presence.

## Research Questions
1) What makes small, always‑on characters feel alive and fun (game feel, idle design, “juice”)?
2) How do games create “moment‑of‑delight” loops without getting annoying?
3) What feedback patterns in games make actions feel immediate and satisfying?
4) What OpenClaw usage patterns are most “shareable” or “wow‑worthy”?
5) Which ideas fit a non‑conversational, action‑first coordinator?

## Source Strategy (Games / Entertainment first)
- Game‑feel / “juice” canon: Vlambeer screenshake, Juice It or Lose It, Steve Swink (game feel loops).
- Game animation craft: 12 principles, secondary action, timing, anticipation, staging.
- 2D/idle animation practices: subtle breathing, weight shifts, micro‑loops, rare idles.
- Game‑dev practitioner articles on animation polish and “feel”.
- OpenClaw product/usage signals (docs + public product pages + community/press).

## Method
1) Collect primary/secondary sources from game design + animation + openclaw usage.
2) Extract patterns into a “Delight Principles” list (e.g., anticipation, follow‑through, clarity, rhythm).
3) Map patterns to ClawDaddy constraints (single sprite, minimal UI, fast acknowledgement).
4) Generate idea backlog (30+). Tag by: effort, novelty, risk, spec‑fit, viral potential.
5) Prioritize into P0/P1/P2 and describe implementation sketches.

## Deliverables
- Curated research notes + citations.
- A prioritized set of delight ideas (with “why this works” tied to game principles).
- A short list of candidate A/B experiments (if desired).

- [x] Gather idle animation guidance from game animation sources.
- [x] Review OpenClaw usage patterns (docs + product pages + press).
- [x] Synthesize into delight principles.
